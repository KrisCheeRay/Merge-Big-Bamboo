# 合成大竹头

一个基于 Vite、原生 JavaScript 和 Matter.js 开发的十级合成网页小游戏。

## 游戏玩法

- 从顶部投放球体，相同等级碰撞后合成下一级。
- 第 1～4 级按照 40%、30%、20%、10% 的概率随机出现。
- 首次合成第 10 级即通关。
- 球体稳定超过顶部警戒线约 1.7 秒后游戏结束。
- 支持鼠标和手机触屏操作。

## 当前功能

- 固定十级合成与指数计分
- 本局分数和浏览器历史最高分
- 重新开始二次确认
- 合成音效开关及总音量控制
- 第 2～9 级随机播放现有合成音效
- 第 10 级固定播放通关音效
- 响应式奶黄与草绿色界面

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```
